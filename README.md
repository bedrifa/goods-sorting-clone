Goods Sorting Clone
==================

## Welcome to "Goods Sorting Clone"  !

This project is replica of the first 5 levels of the "Goods Sorting Match 3” mobile game 
released by Falcon Games.

These docs provide everything you need to download and play the Unity game.

## Getting Started

### 1. Setup Unity

The Unity Editor is required. Download it from <a href="https://unity3d.com/get-unity/download">Unity3d.com/get-unity/download</a>.

1. Open the Unity Project in Unity Version **6000.3.17f1**.
2. Open the Unity Console Window (Unity → Windows → General → Console). Confirm there are no warnings or errors.

### 2. Play Game

**On Android**
1. Open the project folder 
2. Load **.apk** file of `./goods-sorting-clone/Test.apk` to your android phone
3. Run and Play the Android App that you load.

**On Unity Editor**
1. Open the project in the Unity Editor
2. Open the scene of `./goods-sorting-clone/Assets/Scenes/SampleScene.unity`
3. Run and play the Scene
